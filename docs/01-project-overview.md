# Project Overview

## Project Title

Calendly Career Services Scheduling & Automation Implementation

## Business Scenario

This project demonstrates the implementation of a structured Calendly scheduling system for a career coaching and professional development service.

The scheduling environment was designed to support prospective clients, existing coaching clients, and individuals seeking CV and LinkedIn review services.

The goal was to create a streamlined client journey from service selection and qualification through booking, meeting preparation, and post-session follow-up.

## Objectives

The implementation was designed to:

- Create distinct scheduling options for different career services
- Establish controlled business availability
- Collect relevant client information before meetings
- Route clients to the appropriate service based on their needs
- Reduce scheduling conflicts using calendar integration
- Automate meeting reminders and post-meeting follow-ups
- Integrate scheduling activities with CRM and conferencing tools

## Services Configured

Three Calendly event types were created:

1. Career Discovery Call — 30 minutes
2. Career Coaching Session — 60 minutes
3. CV & LinkedIn Review — 45 minutes

Each event type was configured with its own purpose, booking logic, duration, and client intake requirements.

## Technology Stack

The implementation uses:

- Calendly
- Google Calendar
- Google Meet
- HubSpot CRM

## Key Features

The completed system includes:

- Multi-service scheduling
- Customized client intake forms
- Availability and booking controls
- Conditional routing logic
- Automated reminder workflows
- Automated post-meeting follow-up
- Google Calendar integration
- Google Meet integration
- HubSpot CRM connectivity

## Portfolio Purpose

This is a self-directed portfolio implementation created to demonstrate practical Calendly configuration, scheduling operations, workflow automation, client intake design, routing logic, and business-system integration.
